Permite que varios usuarios trabajen sobre el mismo archivo JSON compartido en Google Drive.

1. El usuario principal conecta Drive y guarda datos.

4. Los demás usuarios pegan ese ID aquí y pulsan: “Conectar archivo compartido”.
